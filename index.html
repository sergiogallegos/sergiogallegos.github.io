About Me

I’m a software engineer building products for industrial automation, with a foundation in 14+ years of controls engineering. My experience spans electrical system design and programming PLCs, HMIs, robots, machine vision, and motion control for automated machinery.

Working on those systems led me deeper into the software behind them. Today, I’m applying that experience through systems programming, backend architecture, APIs, and reusable libraries, turning problems I know from machine automation into software products other engineers can build on.

That progression connects my core projects: Rust EtherNet/IP brings PLC connectivity to applications and is already used in production. OpenWebHMI is in development for customer applications on real machinery. tinyPLC is where I study compiler and runtime design through an educational control engine.

My foundation is in Electromechanical Engineering. I’m currently pursuing a Master of Science in Software Engineering, with expected graduation in spring 2027, focusing on architecture, system design, and modern development practices.

Outside of work, I’m a father of two, a soccer fan, and someone who enjoys building systems, from machines to software.

Rust EtherNet/IP

Used in productionHardware verified

  • Validated on real Allen-Bradley hardware: 5069-L320ERMS3 fw35 and 1756-L81ES fw37.

Layer 1 · Control Engine

tinyPLC

In implementationEducation & research

A small PLC compiler and runtime research project for learning how control engines work, from a Structured Text subset through a Rust frontend and LLVM IR to ahead-of-time native code.

  • Implemented: host-tested compiler and ARM Cortex-M object generation.
  • Planned: native runtime integration in C on FreeRTOS / STM32.
  • For education and research only; not for real machinery or safety functions.

An interactive six-axis robot playground for learning robotics and coding with real Python, live forward and inverse kinematics, guided challenges, and a browser-based 3D simulator.

  • Runs entirely in the browser with no account, backend, or server-side data storage.

Compas

Open-source, MIT-licensed professional DJ application built with a Rust audio core, TypeScript UI, and Tauri 2 desktop shell. Compas focuses on true local-file DSP mixing with 4 decks, waveforms, beatgrid and key analysis, sync, key-lock, effects, MIDI learn, cue monitoring, recording, and auto-update support.

  • Active cross-platform desktop project for Windows, macOS, and Linux.
  • Real-time audio engine with in-house time-stretch/key-lock and DJ performance controls.
